# Commit Convention

Use concise conventional-style commit messages.

## Prefixes

- `feat:` product behavior or capability.
- `fix:` bug fix.
- `refactor:` code movement or internal restructuring without intended behavior change.
- `docs:` documentation-only changes.
- `chore:` repository, tooling or maintenance changes.
- `test:` test additions or test fixes.

## Examples

- `refactor: move app into workspace structure`
- `docs: define TalentHub value proposition`
- `fix: protect seed endpoint outside local environments`
